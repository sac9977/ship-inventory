⚓ Ship Inventory Management

Stores & Spare Parts Management — Setup Guide

STEP 1

📂 Unzip the File

Find the file ship-inventory.zip that was sent to you. Unzip it anywhere — the Desktop, Documents, or a dedicated folder.

macOS

Double-click the .zip file
or right-click → "Open"

Windows

Right-click → "Extract All..."
Choose a folder → "Extract"

STEP 2

🐍 Install Python (if not already installed)

Check if you have Python. Open Terminal (macOS) or Command Prompt (Windows) and type:

type this in terminal / command prompt python3 --version

If it shows Python 3.8 or higher, skip to Step 3.

If it says "command not found" or "python is not recognized", download Python:

📥 Download Python

Go to https://www.python.org/downloads/ → click the yellow "Download Python" button → run the installer.

⚠ IMPORTANT (Windows only): During install, CHECK the box that says "Add Python to PATH" or "Add to environment variables" at the bottom of the installer screen!

STEP 3

⚙️ Run the Installer

Open Terminal or Command Prompt, navigate to the ship-inventory folder, and run the setup:

🍎 macOS / Linux
🪟 Windows
open terminal, then type: cd ~/Desktop/ship-inventory
python3 setup.py --ship-name "MV Your Ship Name"

Replace "MV Your Ship Name" with your ship's actual name. This name will appear in the system header and login page.

open command prompt, then type: cd C:\Users\YourName\Desktop\ship-inventory
python setup.py --ship-name "MV Your Ship Name"

Or double-click install.bat if you see it in the folder (without ship name option).

💡 Tip: Naming Your Ship

The --ship-name option lets you customize the system name. Example:

python3 setup.py --ship-name "MV Pacific Star" --port 8080

You can run setup again at any time to change the ship name.

When you see ✅ INSTALLATION COMPLETE!, you're done!

STEP 4

🚀 Start the System

After installation, start the inventory system:

🍎 macOS / Linux

./start.sh

🪟 Windows

Double-click start.bat

Or in command prompt:
start.bat

🌐 Access from Any Device on the Ship

Once started, the server shows you the URL. It will look something like:

http://192.168.x.x:8080

Open this URL on any computer, tablet, or phone connected to the ship's network.

👥 Add Crew Members

🛠️ Troubleshooting

Problem: "python3: command not found"

Python is not installed. Download from python.org/downloads. On Windows, check "Add to PATH" during install.

Problem: "Address already in use"

The server is already running, or another program uses port 8080. Close any existing server, or run: python3 setup.py --port 8888

Problem: Other devices can't access the system

Make sure the computer running the server is connected to the ship's LAN. Check that no firewall is blocking port 8080.

Run the Health Check

If something isn't working, run: python3 healthcheck.py

This will diagnose common issues and tell you exactly what's wrong.
